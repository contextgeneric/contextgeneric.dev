# cgp-serde v0.1.0

This page lists what the first release of cgp-serde provides. cgp-serde rebuilds Serde's
`Serialize` and `Deserialize` traits as components of
[Context-Generic Programming (CGP)](/docs/), a Rust library whose macros generate traits and their
wiring, so each application chooses how every value type is encoded rather than the type fixing it
once.

Released on 2025-11-01.

- **Release post:** [Announcing cgp-serde](/blog/cgp-serde-release)
- **Crate:** [`cgp-serde` 0.1.0 on crates.io](https://crates.io/crates/cgp-serde/0.1.0)
- **Tag:** [v0.1.0](https://github.com/contextgeneric/cgp-serde/tree/v0.1.0)

## Summary

Two components, `CanSerializeValue` and `CanDeserializeValue`, move Serde's `Self` into a
`Value` parameter, so the implementing type is a context that picks a provider for each value
type. The release ships providers that would overlap as blanket impls of Serde's traits, encodings
for bytes and dates, a JSON layer over `serde_json`, and the components that let a deserializer
allocate borrowed values in an arena reached from the context.

## Compatibility

- **Minimum Rust version:** 1.90.
- **CGP version:** built on `cgp` 0.6.0, through `cgp = "0.6.0"`.
- **Crates:** `cgp-serde`, `cgp-serde-extra`, `cgp-serde-json`, `cgp-serde-alloc`, and
  `cgp-serde-typed-arena`, all at 0.1.0.

## Upgrading

This is the library's first release, so there is nothing to upgrade from. Add `cgp-serde` and the
crates whose providers your wiring names beside `cgp`.

## New features

### Components

- **`CanSerializeValue<Value>`** writes a `Value` to a Serde `Serializer` with the context as
  `&self`; its provider trait is `ValueSerializer`, and `Value` may be unsized. See
  [the components](/docs/projects/cgp-serde/reference/).
- **`CanDeserializeValue<'de, Value>`** reads a `Value` from a Serde `Deserializer` with the context
  as `&self`; its provider trait is `ValueDeserializer`.
- **`UseDelegate` dispatch:** both components declare `derive_delegate: UseDelegate<Value>`, so a
  context wires one provider per value type through a `UseDelegate` table.
- **`CanAlloc<'a, T>`**, in `cgp-serde-alloc`, moves a value into storage that lives for `'a` and
  returns a reference to it; its provider trait is `Allocator`. See
  [`CanAlloc`](/docs/projects/cgp-serde/reference/components/can_alloc).
- **`HasArena<'a, T>`**, in `cgp-serde-typed-arena`, is a getter for a `typed_arena::Arena<T>` on
  the context, with `UseDelegate<T>` dispatch.

### Context adapters

- **[`SerializeWithContext`](/docs/projects/cgp-serde/reference/types/serialize_with_context)** pairs a context with a value and
  implements Serde's `Serialize` through the context's `CanSerializeValue`, so any Serde format can
  write the value.
- **[`DeserializeWithContext`](/docs/projects/cgp-serde/reference/types/deserialize_with_context)** implements Serde's
  `DeserializeSeed` through the context's `CanDeserializeValue`.

### Providers in `cgp-serde`

- **[`UseSerde`](/docs/projects/cgp-serde/reference/providers/use_serde)** uses the value's own `Serialize` and
  `Deserialize` impls.
- **[`SerializeString`](/docs/projects/cgp-serde/reference/providers/serialize_string)** writes any `AsRef<str>` as a string and
  reads a `String`.
- **[`SerializeBytes`](/docs/projects/cgp-serde/reference/providers/serialize_bytes)** writes any `AsRef<[u8]>` as bytes and
  reads any `From<&[u8]>`; **[`TryDeserializeBytes`](/docs/projects/cgp-serde/reference/providers/try_deserialize_bytes)** reads
  bytes through `TryFrom`.
- **[`SerializeWithDisplay`](/docs/projects/cgp-serde/reference/providers/serialize_with_display)** writes a `Display` value as a
  string, and **[`DeserializeWithFromStr`](/docs/projects/cgp-serde/reference/providers/deserialize_with_from_str)** reads one
  back through `FromStr`.
- **[`SerializeFrom<T>`](/docs/projects/cgp-serde/reference/providers/serialize_from)** and
  **[`TrySerializeFrom<T>`](/docs/projects/cgp-serde/reference/providers/try_serialize_from)** convert to and from `T` with
  `Into` or `TryInto` and encode `T` through the context.
- **[`SerializeDeref`](/docs/projects/cgp-serde/reference/providers/serialize_deref)** writes what a reference or smart pointer
  points to.
- **[`SerializeIterator`](/docs/projects/cgp-serde/reference/providers/serialize_iterator)** writes a collection iterable by
  reference as a sequence, and **[`DeserializeExtend`](/docs/projects/cgp-serde/reference/providers/deserialize_extend)** reads a
  sequence into any collection that is `Default` and `Extend`.
- **`SerializeFields`** writes a struct that derives CGP's field list, through `HasFields`, as a
  map with each field encoded through the context, and
  **[`DeserializeRecordFields`](/docs/projects/cgp-serde/reference/providers/deserialize_record_fields)** reads such a struct back
  through its optional builder.
- **[`DeserializeDefault<Provider>`](/docs/projects/cgp-serde/reference/providers/deserialize_default)** reads an optional value with
  the inner provider, giving `Default::default()` when the value is absent, such as a JSON `null`.

### Providers in the other crates

- **`cgp-serde-extra`:** [`SerializeHex`](/docs/projects/cgp-serde/reference/providers/serialize_hex) and
  [`SerializeBase64`](/docs/projects/cgp-serde/reference/providers/serialize_base64) encode bytes as strings, and
  [`SerializeRfc3339Date`](/docs/projects/cgp-serde/reference/providers/serialize_rfc3339_date) and
  [`SerializeTimestamp`](/docs/projects/cgp-serde/reference/providers/serialize_timestamp) encode a `chrono` `DateTime<Utc>` as an
  RFC 3339 string or a Unix timestamp.
- **`cgp-serde-json`:** [`SerializeToJsonString`](/docs/projects/cgp-serde/reference/providers/serialize_to_json_string),
  [`DeserializeFromJsonReader`](/docs/projects/cgp-serde/reference/providers/deserialize_from_json_reader), and
  [`DeserializeFromJsonString`](/docs/projects/cgp-serde/reference/providers/deserialize_from_json_string) are `TryComputer`
  providers over `serde_json`, and
  [`CanDeserializeJsonString<T>`](/docs/projects/cgp-serde/reference/types/can_deserialize_json_string) adds a
  `deserialize_json_string` method to every context that has an error type and can deserialize `T`
  through `DeserializeFromJsonString`.
- **`cgp-serde-alloc`:** [`DeserializeAndAllocate`](/docs/projects/cgp-serde/reference/providers/deserialize_and_allocate)
  deserializes a value and allocates it through `CanAlloc`, producing a `&'a Value`.
- **`cgp-serde-typed-arena`:** [`AllocateWithArena`](/docs/projects/cgp-serde/reference/providers/allocate_with_arena)
  implements `CanAlloc` with the arena that `HasArena` reaches.
