# cgp-serde v0.2.0

This page lists what cgp-serde v0.2.0 changed. cgp-serde rebuilds Serde's `Serialize` and
`Deserialize` traits as components of [Context-Generic Programming (CGP)](/docs/), a Rust library
whose macros generate traits and their wiring, and this release moves it onto
[`cgp` v0.7.0](/docs/release-notes/cgp/v0.7.0).

Released on 2026-03-04.

- **Crate:** [`cgp-serde` 0.2.0 on crates.io](https://crates.io/crates/cgp-serde/0.2.0)
- **Compare:**
  [v0.1.0...v0.2.0](https://github.com/contextgeneric/cgp-serde/compare/v0.1.0...v0.2.0)

## Summary

The library requires `cgp` 0.7.0 in place of 0.6.0, the release's one breaking change. Its
components, providers, and context adapters are those of v0.1.0. The providers are written in
`cgp` 0.7.0's syntax, which changes nothing a user sees.

## Compatibility

- **Minimum Rust version:** 1.90.
- **CGP version:** requires `cgp` 0.7.
- **Crates:** `cgp-serde`, `cgp-serde-extra`, `cgp-serde-json`, `cgp-serde-alloc`, and
  `cgp-serde-typed-arena`, all at 0.2.0.

## Upgrading

1. Move the project to `cgp` 0.7.0, following the
   [`cgp` v0.7.0 notes](/docs/release-notes/cgp/v0.7.0#upgrading); see
   [The `cgp` requirement is 0.7.0](#the-cgp-requirement-is-070).
2. Change every cgp-serde crate's requirement to `0.2.0`.

## Breaking changes

### The `cgp` requirement is 0.7.0

Every cgp-serde crate requires `cgp` 0.7.0 where v0.1.0 required 0.6.0. cgp-serde's components
and a project's wiring of them must come from the same `cgp` release, so cgp-serde 0.2.0 does not
compile beside `cgp` 0.6, and a project moves to `cgp` 0.7.0 with it.

## Improvements

- **[`CanDeserializeJsonString<T>`](/docs/projects/cgp-serde/reference/types/can_deserialize_json_string)**
  is generated with `#[cgp_fn]` rather than written by hand. Its method and its `HasErrorType`
  supertrait are unchanged, so code bounded on the trait can still name `C::Error`.
