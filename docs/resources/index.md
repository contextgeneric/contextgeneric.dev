# Resources

[Context-Generic Programming (CGP)](/docs/) enables pluggable trait implementations in Rust, and
the rest of this site's documentation explains how it works. This section collects material about
CGP from beyond those pages, with one page for each kind. For now it holds
[videos](/docs/resources/videos) of talks about CGP, and more kinds, such as events, will be added
in the future.
