# Resources

[Context-Generic Programming (CGP)](/docs/) enables pluggable trait implementations in Rust, and
the rest of this site's documentation explains how it works. This section collects material about
CGP from beyond those pages. Each kind of resource has a section below that says what it holds and
links where it lives.

## Videos

The [Videos](/docs/resources/videos) page collects recorded talks about CGP, for a reader who would
rather watch than read. It holds the RustLab 2025 talk *How to stop fighting with coherence*, which
explains why Rust's coherence rules exist before showing how CGP works within them, and links the
talk's transcript on the blog.

## API documentation

The `cgp` crate's API documentation is on [docs.rs](https://docs.rs/cgp). Its pages list the
traits and macros, but for what each construct does and the code it generates, the
[Reference](/docs/reference) is more complete.

## More to come

For now, these are the only kinds of resource in this section. More kinds, such as events, will be
added here in the future, each with a page of its own.
