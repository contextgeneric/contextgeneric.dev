# Resources

The rest of this site's documentation explains [Context-Generic Programming (CGP)](/docs/), which
enables pluggable trait implementations in Rust. Sometimes, though, you want to meet CGP another
way: in a talk you can watch, in a conversation with other users, or through the crate's API as
rustdoc shows it. This section gathers that material from outside the documentation, and the places
where people discuss CGP.

## Videos

If you would rather watch than read, start with the [Videos](/docs/resources/videos) page. It holds
the RustLab 2025 talk *How to stop fighting with coherence*, which explains why Rust's coherence
rules exist and then shows how CGP works within them. The talk's transcript is on the blog, so you
can also read it at your own pace.

## Community

If you have a question, want to talk with other users, or want to follow CGP's news, the
[Community](/docs/resources/community) page says where to go. It covers the Discord server, GitHub
Discussions, the r/cgp subreddit, and CGP's Bluesky account, with what each one is for.

## API documentation

When you want the API itself, the `cgp` crate's documentation is on [docs.rs](https://docs.rs/cgp),
which lists its traits and macros. Rustdoc cannot show the code a macro generates, though, so for
what each construct does, the [Reference](/docs/reference) is more complete.

## More to come

For now, this section holds videos, the community channels, and the API documentation. More kinds
of resources, such as events, will be added in the future, each on a page of its own, so the links
you find here keep working as the section grows.
